# 量化数据管道 Rubric

> 最佳实践：数据是量化的基石，质量决定策略成败

## 评测项

| ID | 项 | Pass 条件 | 级别 | 最佳实践 |
|----|-----|----------|------|---------|
| P1 | 完整性 | 数据无缺失，覆盖所有标的 | BLOCKER | 全量采集 |
| P2 | 及时性 | 数据延迟 < {DELAY_MINUTES} 分钟 | BLOCKER | 实时性要求 |
| P3 | 准确性 | 数据与源一致，无异常值 | BLOCKER | 数据质量 |
| P4 | 清洗 | 异常值已处理 | normal | 数据清洗 |
| P5 | 校验 | 校验规则通过 | BLOCKER | 质量门禁 |
| P6 | 监控 | 数据延迟/缺失监控有效 | normal | 可观测 |
| P7 | 回灌 | 缺失数据可回灌 | normal | 容错能力 |
| P8 | 存储 | 数据存储成本可控 | normal | 成本优化 |

## 数据类型

| 类型 | 频率 | 延迟要求 |
|------|------|---------|
| 行情 | 实时 | < 1 秒 |
| 财务 | 日频 | T+1 |
| 因子 | 日频 | 盘前 |
| 宏观 | 月频 | 发布后 |

## 数据校验

```python
# 价格校验
- 价格 > 0
- 涨跌幅 < 20%（ST 除外）
- 成交量 > 0

# 财务校验
- 资产 = 负债 + 权益
- 收入 >= 0
```
