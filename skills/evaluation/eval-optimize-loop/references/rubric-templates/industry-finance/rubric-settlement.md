> 合规要求：T+0 账务对账，T+1 银企对账，分厘不差

## 清算流程

```
订单采集 → 清算预处理 → 资金计算 → 账务处理 → 对账 → 完成
```

## 对账检查

- 订单金额 = 清算金额
- 清算金额 = 账务金额
- 账务借方 = 账务贷方

## 占位符

- `{DEADLINE}`: 如 23:00
