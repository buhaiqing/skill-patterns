# 域分组指南

## 分组原则

| 信号 | 通常属于同一域 |
|------|---------------|
| 同一测试文件 | 是 |
| 同一子系统目录 | 可能是 |
| 同一错误堆栈根因 | 是 |
| 不同 API 端点无关失败 | 否 → 可并行 |

## 示例

**可并行**：
- `tests/auth.test.ts` 失败 + `tests/billing.test.ts` 失败
- 前端样式问题 + 后端 API 500（无共享改动）

**不可并行**：
- 同一 migration 导致的多表失败
- 共享 `config.ts` 改坏导致的连锁测试失败

## 隔离策略

| 场景 | 策略 |
|------|------|
| 仅读调查 | 隔离 prompt 即可 |
| 并行写代码 | `git worktree` 每 Worker 一个 worktree |
| 并行跑测试 | 不同测试路径分给不同 Worker |
