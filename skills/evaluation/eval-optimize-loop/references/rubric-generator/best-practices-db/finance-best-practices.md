# 金融行业最佳实践

## 资金安全

### 精度控制
- 使用 Decimal/BigDecimal，禁用 float/double
- 分厘不差，精度误差零容忍

### 对账机制
- T+0：账务对账（系统内）
- T+1：银企对账（与银行）
- 差异处理：当日必须解决

## 并发控制

### 幂等设计
- 全局唯一订单号
- 状态机防重入
- 数据库唯一索引

### 锁机制
- 乐观锁：版本号
- 悲观锁：SELECT FOR UPDATE
- 分布式锁：Redis/ZooKeeper

## 合规要求

| 要求 | 实现 | 频率 |
|------|------|------|
| 监管报备 | 重大变更提前30天 | 变更前 |
| 审计日志 | 全链路记录，5年留存 | 实时 |
| 数据隔离 | 生产/测试物理隔离 | 部署时 |
| 灾备演练 | RPO<1分钟，RTO<5分钟 | 季度 |

## 常见故障

- 重复成交：幂等缺失
- 资金差错：精度问题
- 数据不一致：对账延迟
