# 运维行业最佳实践

## 应急响应 SOP

```
1分钟发现 → 5分钟止损 → 15分钟定位 → 30分钟恢复
```

### 止损优先级
1. 数据安全（防止数据丢失/泄露）
2. 服务可用（核心链路）
3. 用户体验（非核心功能）

### 必须保留现场
- 日志快照
- 堆栈信息
- 配置快照
- 监控图表

## 发布部署规范

| 方式 | 适用场景 | 回滚时间 |
|------|---------|---------|
| 蓝绿部署 | 核心服务 | < 1分钟 |
| 金丝雀 | 高风险变更 | 5分钟 |
| 滚动发布 | 低风险变更 | 10分钟 |

## 监控告警

- 告警分级：P0（立即）/ P1（15分钟）/ P2（1小时）
- 告警收敛：5分钟内相同告警合并
- 降噪：过滤已知问题/维护期

## 变更管理

> 80% 故障来自变更

- 变更评审：双人确认
- 灰度验证：先灰度后全量
- 回滚演练：每月演练
