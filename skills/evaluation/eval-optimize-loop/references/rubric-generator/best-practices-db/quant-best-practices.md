# 量化交易最佳实践

## 策略回测

### 数据质量
- 清洗异常值（涨跌停、停牌）
- 处理复权/除权
- 避免前视偏差（look-ahead bias）

### 过拟合控制
- 样本内/样本外测试
- 滚动回测（walk-forward）
- 参数稳健性检验

### 成本模型
```
总成本 = 手续费 + 滑点 + 市场冲击

滑点 = f(成交量, 波动率, 流动性)
```

## 实盘交易

### 差异管理
- 实盘 vs 回测参数一致性检查
- 逐笔成交对比
- 差异归因分析

### 风控体系
| 层级 | 触发条件 | 动作 |
|------|---------|------|
| 单笔风控 | 单笔亏损 > X% | 暂停该策略 |
| 日累计风控 | 当日亏损 > Y% | 全部暂停 |
| 回撤风控 | 回撤 > Z% | 减仓/清仓 |

### 异常处理
- 价格跳变 > 3σ：自动暂停
- 连接断开：自动重连，人工确认
- 委托失败：报警，人工介入

## 监控指标

- P&L（盈亏）
- 希腊字母（期权）
- VaR（风险价值）
- 夏普比率
- 最大回撤
