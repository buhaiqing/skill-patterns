# 配置变更 Rubric

> 最佳实践：80% 故障来自变更，配置变更是高危操作

## 评测项

| ID | 项 | Pass 条件 | 级别 | 最佳实践 |
|----|-----|----------|------|---------|
| C1 | 变更评审 | 配置变更已评审（双人） | BLOCKER | 配置即代码 |
| C2 | 灰度验证 | 已在灰度环境验证 | BLOCKER | 灰度先行 |
| C3 | 回滚方案 | 有明确回滚命令，< 5分钟 | BLOCKER | 可快速回滚 |
| C4 | 影响评估 | 影响范围已识别（服务/用户） | BLOCKER | 变更风险评估 |
| C5 | 监控验证 | 变更后监控指标正常 | BLOCKER | 监控驱动 |
| C6 | 审计 | 变更记录完整（who/when/what） | normal | 审计追溯 |
| C7 | 自动化 | 配置已版本化（Git/SVN） | normal | IaC |

## 定制说明

- C1: 生产环境配置强制，测试环境可选
- C3: 需提供具体回滚命令，不能是「手动回滚」
