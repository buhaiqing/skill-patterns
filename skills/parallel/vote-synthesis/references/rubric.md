# Vote Synthesis — 评分 Rubric（模板）

对分歧答案按维度打分（0–3），总分高者胜。平手则 escalate。

| 维度 | 3 分 | 0 分 |
|------|------|------|
| **正确性** | 与已知事实/测试一致 | 明显错误 |
| **完整性** | 覆盖全部子问题 | 遗漏关键点 |
| **可验证性** | 含命令/证据 | 纯断言 |
| **安全性** | 无危险操作 | 含 secrets/破坏性建议 |
| **简洁性** | 切题不冗余 | 冗长跑题 |

## BLOCKER 规则

任一路答案在**安全性**维度为 0 且有实质风险 → 该路**淘汰**，不参与计分。

## 多数派规则

- ≥ 2/3 文字结论一致 → majority，confidence=high
- 2/3 一致但细节不同 → majority，confidence=medium，列差异
