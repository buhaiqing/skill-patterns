# 金融交易系统 Rubric

> 行业合规要求：资金安全、并发安全、对账一致、监管可审计

## 评测项

| ID | 项 | Pass 条件 | 级别 | 行业合规要求 |
|----|-----|----------|------|------------|
| F1 | 资金安全 | 资金计算精度无误，分厘不差 | BLOCKER | 会计准则，禁用 float |
| F2 | 并发安全 | 锁机制正确，无竞态条件 | BLOCKER | 交易隔离，防止重复成交 |
| F3 | 对账 | 上下游对账一致 | BLOCKER | T+0账务对账，T+1银企对账 |
| F4 | 幂等 | 重复提交无重复成交 | BLOCKER | 订单唯一键 + 状态机 |
| F5 | 熔断 | 异常场景触发熔断降级 | BLOCKER | 监管要求，保护系统 |
| F6 | 审计 | 全链路可审计，日志完整 | normal | 5年留存，不可篡改 |
| F7 | 压测 | 峰值容量 3 倍验证 | normal | 大促保障 |
| F8 | 合规 | 监管报备（如适用） | normal | 重大变更提前30天报备 |
